# Sharing Oracle Workspaces

Oracle workspaces should be shareable as repositories, not only as local machine setups.

The important idea is that the repository carries:

- source code
- workspace configuration
- onboarding notes
- AGENTS.md guidance
- automation scripts

That makes the repository itself an onboarding asset.

For a practical explanation of what belongs in `AGENTS.md`, see [AGENTS.md Guide](agents-guide.md).

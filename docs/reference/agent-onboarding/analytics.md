# Analytics Agent Onboarding

Analytics work should preserve durable source assets:

- `.py`
- `.md`
- `.csv`
- `.json`
- `.xlsx`

Generated outputs such as `.pdf`, `.html`, `.png`, and `.jpg` are reproducible build artifacts.

Preferred interactive environment:

- `marimo`

Alternative for classrooms and workshops:

- `jupyterlab`

Users do not need prior Python knowledge to begin, but generated code should still be reviewed and explained.

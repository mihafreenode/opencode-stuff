# Publishing Agent Onboarding

Recommended publishing order:

1. Markdown
2. Typst
3. LaTeX

Why:

- Markdown is the simplest and most portable default.
- Typst is modern, concise, and AI-friendly.
- LaTeX remains important for academic compatibility and existing templates.

Durable source assets:

- `.md`
- `.typ`
- `.tex`
- `.bib`
- `.svg`

Generated artifacts:

- `.pdf`
- `.html`
- `.png`
- `.jpg`

Standard workflow:

`source -> build -> validate -> inspect`

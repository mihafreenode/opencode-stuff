# Education Agent Onboarding

Use indexed educational references first.

Audience guidance:

- elementary school: conceptual explanations and simple charts
- middle school: survey analysis, graphing, introductory coding
- high school: statistics, regression, environmental data, economics projects
- technical school: process monitoring, KPI reporting, quality analysis
- introductory university: Python, statistics, data science, machine learning basics

Treat AI as a tutor and assistant, not as a replacement for understanding.

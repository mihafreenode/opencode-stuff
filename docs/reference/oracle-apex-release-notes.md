Purpose:
Curated official entry points for Oracle APEX release notes and version-specific behavior changes.

Version note:
The indexed release notes are for APEX 24.2. They are not labeled as the universally current release. Use `docs/reference/oracle-knowledge-map.yaml` and Oracle's landing page to select notes matching the deployed and target versions.

When to use:
- checking whether a feature or package changed between versions
- confirming new capabilities, deprecations, or upgrade notes
- investigating behavior differences between the local runtime and an indexed documentation version

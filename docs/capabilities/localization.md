# Localization

## What It Is

This capability documents the multilingual review and language-sensitive workflows available in the workspace.

## Why Use It

Use it when you need to validate localized content, proofread multilingual text, or support language-specific review workflows.

## Available Tools

### Hunspell Dictionaries

Purpose: Spell checking for supported languages.

Supported workflows: multilingual proofreading, dictionary validation, localization review.

Common use cases: review English text, review Slovenian text.

### OCR and Text Pipelines

Purpose: Feed extracted text into localization-aware review flows.

Supported workflows: post-OCR proofreading, translation review support, multilingual document cleanup.

Common use cases: clean extracted text, review converted documents.

## Typical Tasks

- Proofread multilingual documents before publishing.
- Validate supported language workflows after OCR or conversion.
- Use localization review as part of reporting and documentation pipelines.

## Examples

- Check Slovenian and English content after OCR extraction.
- Review language-sensitive report drafts before handoff.

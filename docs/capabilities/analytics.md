# Analytics

## What It Is

This capability highlights the analysis-oriented workflows supported by the workspace, especially around spreadsheets, tabular documents, PDF deliverables, and derived reporting artifacts.

## Why Use It

Use it when you need to inspect spreadsheets, summarize business data, or move from raw documents into analytical reporting.

## Available Tools

### Python

Purpose: General-purpose scripting for analytical pipelines.

Supported workflows: data processing, spreadsheet automation, report preparation.

Common use cases: parse exported data, build analysis helpers.

### LibreOffice

Purpose: Spreadsheet and Office document processing.

Supported workflows: spreadsheet conversion, Office-to-PDF export, headless office workflows.

Common use cases: inspect XLSX inputs, convert spreadsheet outputs.

### Reporting Tooling

Purpose: Turn analytical results into durable reports.

Supported workflows: PDF reporting, document packaging, reproducible reporting.

Common use cases: build business reports, package analytical findings.

## Typical Tasks

- Process spreadsheet exports and turn them into readable reports.
- Combine tabular analysis with PDF or Office deliverables.
- Prepare repeatable analytical outputs for teammates.

## Examples

- Convert spreadsheet or Office content into PDF reports.
- Use Python and document tooling to prepare dashboard or report inputs.

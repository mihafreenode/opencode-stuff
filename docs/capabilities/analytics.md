# Analytics

## What It Is

This capability highlights the analysis-oriented workflows supported by the workspace, especially around spreadsheets, tabular data, Marimo notebooks, statistical analysis, charts, and derived reporting artifacts.

## Why Use It

Use it when you need to inspect spreadsheets, summarize business data, explore datasets, teach data literacy, or move from raw inputs into analytical reporting.

## Available Tools

### Python

Purpose: General-purpose scripting for analytical pipelines.

Supported workflows: data processing, spreadsheet automation, report preparation, reproducible analysis.

Common use cases: parse exported data, build analysis helpers, explain code with AI assistance.

### Marimo

Purpose: Preferred interactive analytics environment built from regular Python files.

Supported workflows: reactive notebooks, analytics as code, Git-friendly exploratory work.

Common use cases: build notebooks from datasets, iterate on charts, share analytical apps.

### JupyterLab

Purpose: Familiar classroom and workshop alternative.

Supported workflows: teaching, experimentation, notebook-based exercises.

Common use cases: school labs, beginner-friendly notebook sessions.

### LibreOffice

Purpose: Spreadsheet and Office document processing.

Supported workflows: spreadsheet conversion, Office-to-PDF export, headless office workflows.

Common use cases: inspect XLSX inputs, convert spreadsheet outputs.

### Reporting Tooling

Purpose: Turn analytical results into durable reports.

Supported workflows: PDF reporting, document packaging, reproducible reporting.

Common use cases: build business reports, package analytical findings.

## Typical Tasks

- Process spreadsheet exports and turn them into readable reports.
- Combine tabular analysis with PDF or Office deliverables.
- Prepare repeatable analytical outputs for teammates.
- Teach introductory analytics, statistics, and survey analysis.
- Use AI assistance to explain Python, debug scripts, and generate first drafts.

## Examples

- Convert spreadsheet or Office content into PDF reports.
- Use Python and document tooling to prepare dashboard or report inputs.
- Launch `marimo edit` for Git-friendly interactive analytics.
- Generate KPI summaries from CSV, JSON, or XLSX inputs.

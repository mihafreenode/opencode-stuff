# OCR

## What It Is

This capability documents the OCR tooling that can extract text from scanned documents, image files, and PDF pages inside the workspace.

## Why Use It

Use it when you need searchable text from scanned documents, screenshots, or PDFs before analysis, spell checking, or localization work.

## Available Tools

### Tesseract

Purpose: Extract text from images and scanned document pages.

Supported workflows: scanned PDF extraction, image text extraction, OCR pipeline automation.

Common use cases: convert scanned PDFs to searchable text, extract text from screenshots or photos.

### PDF Imaging Helpers

Purpose: Prepare scanned PDF pages for OCR.

Supported workflows: PDF page conversion, image preprocessing, OCR batching.

Common use cases: split PDF pages to images, improve OCR input quality.

## Typical Tasks

- Extract text from scanned documents before analysis or proofreading.
- Convert PDF pages to images and run OCR in batches.
- Combine OCR output with document-processing or localization workflows.

## Examples

- Run OCR over scanned PDF pages and feed the extracted text into spell-checking.
- Extract text from image-based reports before converting them into searchable deliverables.

# Spell Checking

## What It Is

This capability describes the installed spell-checking tooling and the language-aware proofreading workflows available in the workspace.

## Why Use It

Use it when you need repeatable proofreading for extracted text, generated reports, or multilingual content.

## Available Tools

### Hunspell

Purpose: Dictionary-based spell checking for workspace text.

Supported workflows: proofreading, language validation, post-OCR cleanup.

Common use cases: check English content, check Slovenian content.

### Workspace Text Pipelines

Purpose: Combine extracted or generated text with spell-check workflows.

Supported workflows: OCR cleanup, report proofreading, translation review support.

Common use cases: validate OCR output, review generated manuals.

## Typical Tasks

- Proofread English and Slovenian text after conversion or OCR.
- Run dictionary checks on documentation and reports.
- Use spell-checking as part of localization or review workflows.

## Examples

- Check OCR-extracted text before publishing a searchable PDF.
- Validate multilingual report drafts before handoff.

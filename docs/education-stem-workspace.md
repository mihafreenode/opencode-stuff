# Education & STEM Workspace

The Education & STEM workspace is one of the flagship examples of the platform.

It is designed to make modern analytical and scientific tools more accessible through a repository-first, AI-assisted, reproducible learning environment.

Its learning story is:

```text
Curiosity
    ↓
Exploration
    ↓
Project
    ↓
Understanding
```

## Goals

- make analytics and STEM workflows approachable for beginners
- support guided learning through durable repository content
- turn experiments, charts, notebooks, and reports into repeatable project assets
- help learners ask better questions and understand the answers

## What This Workspace Combines

- Analytics & Reporting
- Education Knowledge Pack
- Sample Data Pack
- Skills
- AI-assisted learning
- Reproducible notebooks

## Onboarding Flow

This workspace follows the same repository discovery philosophy as the rest of the platform:

## Recommended Learning Path

1. Start with one question, not one tool.
2. Read the workspace guide and available knowledge-pack links.
3. Ask OpenCode to suggest a beginner-friendly project structure.
4. Explore a small dataset in Marimo or another supported notebook flow.
5. Build one chart and explain it in plain language.
6. Turn the exploration into a small project or report.
7. Review the generated code, math, and explanation until the result is understood.

## AI-Assisted Learning Guidance

AI should be treated as a tutor and assistant rather than a replacement for learning.

OpenCode is useful for:

- explaining code line by line
- suggesting experiments
- turning questions into small projects
- debugging notebooks and scripts
- helping convert results into charts and reports

Useful questions include:

- Can you explain this Python in beginner-friendly language?
- What experiment could I run with this dataset?
- Can you help me visualize this in a way that is easier to understand?
- What does this chart suggest, and what should I verify before trusting it?
- Can you help me write a short science or statistics report from these results?

The goal is not to automate learning away. The goal is to make strong tools more accessible while keeping understanding at the center.

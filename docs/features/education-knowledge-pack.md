# Education Knowledge Pack

The Education Knowledge Pack is a reference-only feature. It does not install heavy runtime dependencies and it does not mirror external content.

Use it to give OpenCode a stable set of deeplinkable references for:

- elementary school explanations
- middle school projects
- high school statistics and STEM work
- technical school analytics and KPI exercises
- introductory university Python, statistics, and data science

Start with:

- `docs/reference/education-knowledge-map.yaml`
- `docs/reference/agent-onboarding/education.md`

This pack is intended to improve explanations, citations, lesson ideas, classroom activities, and project suggestions while keeping the original public sources authoritative.

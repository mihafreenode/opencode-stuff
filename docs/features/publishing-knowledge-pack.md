# Publishing Knowledge Pack

The Publishing Knowledge Pack is a reference-only feature for reproducible publishing workflows.

It helps agents navigate:

- Markdown publishing
- Typst authoring
- LaTeX and TeX Live references
- citations and bibliography workflows
- SVG and diagram tooling
- PDF validation and inspection

Start with:

- `docs/reference/publishing-knowledge-map.yaml`
- `docs/reference/agent-onboarding/publishing.md`

Source assets are durable. Generated PDFs and rendered images are build artifacts that should be reproduced from source.

# Skill Packs

Skill packs are durable, version-controlled guidance for repeatable agent workflows.

Use this structure:

- `skills/oracle/`
- `skills/analytics/`
- `skills/education/`
- `skills/publishing/`

Skills should be:

- reusable
- composable
- agent-friendly
- reviewable in Git

Reference skills from onboarding docs and knowledge packs instead of duplicating long guidance in `AGENTS.md`.

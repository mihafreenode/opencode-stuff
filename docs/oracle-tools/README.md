# Oracle Tools Index

This index catalogs Oracle tooling that is included directly or documented for onboarding.

Start with the [Oracle and Oracle APEX Integration map](../integrations/oracle-apex.md) for implemented, optional, and experimental status. An item in this tool index does not by itself mean that every workflow is fully automated.

## Included Or Documented Tools

- [SQLcl](sqlcl.md)
  - Oracle command-line client for scripts, schema work, and APEX automation
  - onboarding relevance: first tool to learn in Oracle PL/SQL Demo
- [Data Pump](data-pump.md)
  - Oracle schema and data export/import workflow
  - onboarding relevance: conceptual generated helpers only; operational commands require DBA review and environment setup
- [ORDS](ords.md)
  - Oracle REST Data Services for APEX and HTTP access
  - onboarding relevance: required for Oracle APEX Demo and Oracle APEXlang Demo
- [APEX Export / Import](apex-export-import.md)
  - official application movement workflow
  - onboarding relevance: bridge between APEX Builder and source-controlled workflows
- [APEXlang](apexlang.md)
  - Oracle's Open Application Specification Language for APEX
  - onboarding relevance: advanced source-control stage after APEX basics
- [SQL Developer](sql-developer.md)
  - Oracle desktop IDE for browsing and querying
  - onboarding relevance: optional GUI path for first-time Oracle users

## Related APEX Capabilities

The Oracle APEX Demo also introduces standard APEX capabilities such as:

- Interactive Reports
- Interactive Grids
- Charts
- Dashboards
- CSV or spreadsheet-style export where supported

These are explained from the onboarding path in:

- [Oracle APEX Demo](../oracle-apex-demo.md)

# OpenCode Workspace 0.1.0

This release establishes the consolidated cross-platform release contract for the durable workspace manager.

## Included packages

- Primary self-contained Windows `win-x64` package.
- Self-contained Linux `linux-x64` evaluation package.
- Self-contained macOS `osx-arm64` evaluation package. The macOS binaries are currently unsigned and may show a Gatekeeper warning.

Each archive uses the canonical flat layout and includes an adjacent SHA-256 sidecar and `release-manifest.json` provenance metadata.

## Validation

Publication requires mandatory Core, CLI, Avalonia, RemoteBridge, MCP, API FastIntegration, PackageIntegration, and native RID package validation. Docker, Oracle, and real Cloudflare suites remain optional environmental validation.

# OpenCode Workspace 0.1.0-rc.5

This release candidate verifies the complete existing Oracle-capable release stack while preserving the normal optional Oracle release policy.

## Release candidate update

- Full Oracle/APEX integration and packaged Oracle MCP verification candidate.

## Included packages

- Primary self-contained Windows `win-x64` package.
- Self-contained Linux `linux-x64` evaluation package.
- Self-contained macOS `osx-arm64` evaluation package. The macOS binaries are currently unsigned and may show a Gatekeeper warning.

Each archive uses the canonical flat layout and includes an adjacent SHA-256 sidecar and `release-manifest.json` provenance metadata.

## Validation

Publication requires the ordinary release gates plus the full Oracle verification job for this candidate. Other main, RC, and stable runs retain optional environmental Oracle validation.

The verification scope and existing live-coverage boundaries are documented in [Full Oracle Verification Candidate](../testing/full-oracle-verification.md).

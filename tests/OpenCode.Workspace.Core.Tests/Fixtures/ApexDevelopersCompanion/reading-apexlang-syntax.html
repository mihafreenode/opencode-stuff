Component Syntax

Components use a block with a type, optional identifier, and parentheses. Properties can be omitted when Builder defaults are acceptable.

Arrays use repeated child entries. Source files follow exported naming conventions.

Identifiers And Scope

A component identifier is unique only within its component scope. A page item can share a label with a shared component because the scopes differ.

Component References

Use @ for local references and @/ for Global Page and Universal Theme references.

Properties And Property Groups

Property groups keep related properties together.

Embedded Languages

Use fenced code blocks for SQL, PL/SQL, JavaScript, HTML, and CSS. Distinguish javascript-browser from javascript-mle.
